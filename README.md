Welcome to my 42 cursus portfolio, a central archive of the software engineering projects I have developed during my time at 42.

## About 42

42 is a globally recognized coding school built on a peer-to-peer, gamified learning model. The curriculum is entirely project-based and operates without teachers or traditional classes. This environment demands rigorous problem-solving, self-directed research, and deep technical mastery, as all code must strictly adhere to the school's structural guidelines (The Norm) and pass rigorous automated and peer evaluations.

## Technical competencies

The curriculum begins with low-level C programming before advancing into algorithmic challenges, system administration, and object-oriented design. The projects within this portfolio demonstrate strong architectural fundamentals, with a sustained, intensive focus on **C++ software development**. Key skills acquired include:

* **Low-Level Systems & Memory:** custom standard library implementations, pointer arithmetic, Unix system calls, and strict memory leak prevention.
* **Object-Oriented Architecture:** extensive implementation of C++98, emphasizing canonical orthodox form, encapsulation, and robust class-based logic.
* **Advanced Class Mechanics:** managing complex state through deep memory copying, abstract classes, and pure virtual functions.
* **Data Handling & Complex Logic:** developing fixed-point arithmetic overloads, building reliable file stream parsing, handling error management, and routing commands via class methods.
